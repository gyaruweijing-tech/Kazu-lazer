# カズレーザー（光線）

まじで、ただカズレーザーがレーザーを撃てるだけのボケWebアプリ。

## これは何
- ランダムに現れる **点**（標的）をタップ／クリックすると、カズレーザーの **口からレーザー** が出て撃ち落とす。
- レーザーはモンスト級に煌びやか（多層グロー＋火花＋パーティクル＋画面フラッシュ＆シェイク）。
- 撃つたびに **CHARGE** が溜まる。MAXでもう1発撃つと…
  **「回転乱れ撃ち！」** — カズレーザーがぐるぐる回転しながら光線を360°ばら撒いて全消し。
- 目も光る。

## 遊び方
1. `index.html` をブラウザで開く（サーバー不要。`assets/kazu.png` を同梱）。
2. 「撃つ」を押す。
3. 点を撃つ。以上。

## 構成
- `index.html` … 全部（マークアップ＋CSS＋JS）。依存ゼロ・ビルドなし。
- `assets/kazu.png` … キャラ画像（透過済み）。

音はオン/オフ切替（右上🔊）。
